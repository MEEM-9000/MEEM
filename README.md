# MEEM — Elke & Mark

A simple, atmospheric GitHub Pages homepage built around Meem's live performance photograph.

## Replace these items

- `audio/meem-live.mp3` — add a Meem recording.
- YouTube / Instagram / Facebook links in `index.html`.
- Event dates, venues and details.
- Booking email address.

## Publishing

Upload the contents of this folder to a GitHub repository.

Then choose:

**Settings → Pages → Deploy from a branch → main → / (root) → Save**

The supplied photograph is credited in the page as **Photo © Luc Gevaert**.
